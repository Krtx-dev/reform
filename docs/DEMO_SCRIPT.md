# Demo script (≤ 3:00)

Setup before recording: `npm run build && npm start`, open `http://localhost:3000` in a fresh browser profile at 1440×900. Settings → Reset demo factory if it was used before. Close the judge guide panel when it appears (or keep it as a visual cue). Numbers below are from `docs/BENCHMARKS.md` (seed 42, material objective); the live search with the default 4 s / 600-iteration budget may differ slightly — read the numbers off the screen.

| Time | Screen | Narration |
|---|---|---|
| 0:00–0:20 | Landing page; hero animates from scattered pieces into remnants | "Workshops bin fabric that's still good — offcuts, roll ends, seconds with a stain — because working out what each odd piece can still become is a hard puzzle. REFORM solves that puzzle. Waste is a design constraint, not an endpoint." |
| 0:20–0:45 | Launch workspace → Explore the demonstration factory → Inventory | "This is a synthetic workshop: 41 remnants across ten fabrics. Each is stored in millimetres with its grain, its defects — these red hatched zones — and rules like this directional print that can't be rotated." |
| 0:45–1:05 | Optimizer → Products tab (quantities, tote is a priority star) → Constraints tab (objective + formula, clearance 4 mm, margin 5 mm) | "We ask for eight products — totes, cushions, pouches, coasters. A product only counts if every one of its pieces fits. We optimize for material recovery; the score formula is right here." |
| 1:05–1:40 | Press **R**. Progress bar and canvas update live. Then Technical view (5), hover a piece, scrub the timeline / press play on "Search snapshots" | "The search runs in a Web Worker: 64 constructive strategies, then seeded local search. These are real best-so-far layouts, not an animation. Every result is re-checked by an independent validator — containment, clearance, defects, grain, rotation, completeness. Roughly 63–64 % of the usable fabric becomes about 55 complete products." |
| 1:40–2:05 | **Compare baseline** → Comparison view side by side; Inspector shows Δ pts | "Same inputs, conventional row-by-row cutting, biggest products first: about 49 %. The optimizer recovers roughly 14 points more of the same fabric here; across our eight benchmark datasets the gain ranges from under 2 to almost 20 points — and the lab reports it honestly when a simpler method wins." |
| 2:05–2:25 | Materials tab → untick **R12 Tablecloth second** → OUTDATED banner → Re-run | "Inventory changes — that tablecloth just got used elsewhere. The old plan is immediately marked outdated, we re-run, and REFORM shows exactly which products we gained or lost." |
| 2:25–2:45 | Save plan → Plans → SVG export (open file), PDF export, Commit → commit again (refused) → Impact page | "Save it as a plan, export a true-scale SVG cutting template and a PDF report, and commit when cutting starts — inventory is deducted once, never twice. Impact separates proposed, committed and verified material; we don't claim carbon numbers we can't defend." |
| 2:45–3:00 | Benchmark page with results table | "Everything runs in the browser, open source, no keys. Next: irregular nesting, off-cut return and verified recovery logging, so remnants become resources by default." |
